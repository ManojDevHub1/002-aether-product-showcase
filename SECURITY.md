# Security Policy

## Supported Versions

Only the latest stable release of **AETHER ONE** receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **AETHER ONE**, please send a confidential email to `security@aether.design`.

Please include:
1. Description of the vulnerability and potential impact.
2. Steps to reproduce or proof-of-concept code.
3. Suggested fix (if available).

We take security seriously and will acknowledge your report within 24 hours.
